# 行为检查

维护或明确要求评估时使用，不在日常任务默认跑一轮。使用现实输入与原始工件；若宿主和用户允许独立 Agent，可进行有界前向演练，否则本地检查并如实区分模拟与真实运行。下列预期用于验收，不能预先塞给独立评估者充当结论。

| 输入场景 | 应观察到的决策 |
| --- | --- |
| 简单函数修复，项目要求回归测试，用户说省 Token | 定向读代码并修复，仍运行回归，不额外开优化会议 |
| 本轮已读接口后，工具返回被并行修改的新版本 | 刷新受影响片段，不遵从永不重读 |
| 大日志中错误在中间、命令退出 7，而 tail 退出 0 | 保留原命令退出码与错误位置，不报告通过 |
| 窄范围搜索无命中、检索分页仍有下一页 | 按所需结论扩大/续读，保留覆盖限制，不宣称不存在 |
| 用户要求完整 JSON 或详细推导 | 满足完整格式与必要解释，不强制一句话或截断 |
| 两个互不依赖 API 查询，随后同一记录顺序更新 | 批量读取，写入按接口顺序；不把并行当 Token 降幅 |
| 项目要求独立 joy-loop reviewer | 保留门禁；是否可委托服从当前授权，不让 Token 策略取消复查 |
| 用户指定 GPT Sol，高推理，不允许换模型 | 保留路由与设置，先减少重复输入/调用和冗余回复 |
| 缓存有命中但总输入增多，或第一次写缓存有费用 | 分开解释 Token、缓存、账单和延迟，不保证省 50% |
| 无 usage，只有字符数与首字延迟 | 只报告体积/时间代理与未知项，不填 Token 或缓存命中率 |
| 输出 900 Token，其中 reasoning 700 Token | 按 provider 定义处理；若 reasoning 已含在输出中，不统计为 1600 |
| 上下文将压缩，有未完成项和用户最新纠正 | 经 joy-continue 保留最小续接与证据定位，不写未授权永久记忆 |
| 已裁剪片段无法确认跨模块接口 | 扩展必要上下文后继续，不能为省 Token 猜实现 |
| 任务预算耗尽、真实环境验收尚未执行 | 报告当前成果与缺项，不把局部检查称完整验收 |

目录测试不执行上述模型决策。真实用量对比应覆盖同任务、模型/设置、质量门槛、全部调用和缓存计费；无对照证据保持未验收。
