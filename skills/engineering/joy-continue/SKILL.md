# JoyStack · Continue

跨技能交接按名称使用当前宿主已发现的 Skill，不要求相邻安装目录；缺少所需能力时报告缺项，不猜路径或擅自安装。

只保留下一位执行者真正需要的状态：已完成结果及证据、当前分支/文件或运行位置、已确认决定及其适用范围、未解决风险、下一步与阻塞条件。把用户决定、当前事实、方案推断和待验证项分开，保留时间与受众精度。

不要把整个对话、凭据、敏感资料、未经验证的结论或仅供本轮思考的草稿自动写入长期系统。需要持久化时，遵循目标项目的受众、去重、写入和验证协议；没有授权时只输出交接摘要。

续接时先核对记录所指的代码、配置或外部状态是否仍然成立；历史交接是定位线索，不代替当前事实。共享交接标准见套件契约（按技能名发现 `joy-stack`，再从其实际目录读取 `references/stack-contract.md`）。

接手 PR/分支/Agent 工作、恢复中断任务或更新旧变更时，先执行[继承工作核对](references/inherited-work.md)：恢复原目标与最新纠正，判断继续、重做或已被替代，再在授权范围内交给实现与 Git 模块。Git 无冲突不等于方案仍有效，接手也不转移原作者署名或扩大写入权限。
